Welcome to Contribot Docs! This is a documentation site for Contribot, a bot that helps
you track and manage contributors for your projects. Contribot is designed to be easy to 
use, efficient, and flexible, allowing you to customize it to fit your needs and requirements. 
Additionally, its core functionality is to help you determine who is putting in work on your
group projects, as we know that it can be difficult to keep track of who is doing what and its
annoying to have people not pull their own weight. 

We understand this is a common problem in most group projects, and as students, we have
taken it upon ourselves to create a solution that is easy to use and understand for other
students (and anyone who is interested in using it).

## Getting Started with Contribot

* `mkdocs new [dir-name]` - Create a new project.
* `mkdocs serve` - Start the live-reloading docs server.
* `mkdocs build` - Build the documentation site.
* `mkdocs -h` - Print help message and exit.
